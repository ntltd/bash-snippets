# Bash Snippets

Collection of useful bash commands and scripts for everyday development tasks.

## Categories

### Files

- [`active-suffix-all.sh`](./files/active-suffix-all.sh): duplicate with "-active" suffix all files in directory
- [`kebab-case-all.sh`](./files/kebab-case-all.sh): lowercase and replace spaces with dashes for all files in directory

### Images

- [`colorize-white-active-png.sh`](./images/colorize-white-active-png.sh): colorize all PNG files with "-active" suffix to white
